# Muaaz Din Ahmad — Cinematic Website

## GitHub Pages पर चलाने का तरीका

1. GitHub पर नया **Public repository** बनाओ, जैसे `muaaz-din-ahmad`.
2. इस ZIP को extract करो.
3. इसके अंदर की **4 files** (`index.html`, `style.css`, `script.js`, `hero.png`) repository के root में upload करो.
4. GitHub में **Settings → Pages** खोलो.
5. **Build and deployment → Deploy from a branch** चुनो.
6. Branch में `main` और folder में `/ (root)` चुनकर **Save** करो.
7. थोड़ी देर बाद GitHub Pages का URL दिखेगा. उसी URL को खोलकर वेबसाइट देखो.

### Important
यह पूरी तरह static website है, इसलिए GitHub Pages पर किसी server की जरूरत नहीं है.
आँखों का blink और hair-wind CSS animation से बनाया गया है; original photo को वीडियो में बदले बिना visual motion मिलता है.
